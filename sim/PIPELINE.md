# Sim pipeline (one line per stage, kept current)

Albus's MuJoCo scene (`third_party/ur5e-manip-sim`) on macOS, in its own uv env (`sim/pyproject.toml`), used to test the stages after perception. Stage numbers refer to the Pipeline section of `../README.md`.

1. **Assets** (`sim/make_assets.sh`): downloads the YCB red mug (025_mug), converts it and Albus's teapot (scaled to 0.75) into `sim/assets/`, with collision hulls and the teapot's `frames.json` scaled to match.
2. **Scene** (`sim/scenes/pour_tea_real.json`): teapot and mug placed where perception put the real ones (base_link mapped into robosuite's base frame) but 25 cm closer to the robot (at 0.87–0.95 m the real ones are at the edge of the UR5e's reach), with the teapot's spout facing the mug.
3. **Capture** (`sim/capture.py`): moves a camera to the real RealSense's pose and intrinsics (`--camera-from` takes them from a real run's exported camera instead of the built-in bag's), and writes RGB, depth, the robot mask, each object's ground-truth mask, and `meta.json` (K, camera and base poses, joints, and each object's mesh path and body pose).
4. **Perception** (`python -m omnimanip.run --sim DIR --gt σ_t σ_r`): the frame packet, SAM 3 marks and Gemini stage split run as on the robot (stages 1–3). Stages 4–8 are replaced by ground truth: each mark takes the sim object with the best-overlapping mask, its visual mesh, and its body pose plus Gaussian noise (σ_t m per axis, and σ_r° per axis about the object's origin). Orient Anything still reads the real crop, so stage 9 sets the canonical frame as on the robot.
5. **Planning** (stages 11–16): the rest of `python -m omnimanip.run` on the same output dir (`sim/run_batch.sh` runs perception through execution). AnyGrasp is Albus's server on 5666; `ANYGRASP_PORT=5676` uses ours (same code and image) when his is down.
6. **Execution** (`sim/execute.py --run DIR --frame FRAME [--view]`): cuRobo's map gets the run's fitted table plane as a slab, as on the robot; the grasp primitive (cuRobo-planned move to the 8 cm pre-grasp, straight forward, settle, close, 10 cm lift; the marker's grasps come from a privileged antipodal proposer on its ground-truth mesh, `--sim-mesh-grasps`), then the pour as a cuRobo-planned move to the O9 target carrying the teapot as spheres, with O9 re-solved on every tracker update until within 2 cm and re-planned when the target moves, aborting if the object leaves the grip; the tracker is ground truth carrying the run's registration error and joint paths are tracked by Albus's Tracker on friction physics; writes exec.json and exec.mp4 (`--view` opens a live viewer: run it with mjpython).
